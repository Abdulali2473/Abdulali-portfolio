# موقع Abdulali Almarzooq — تصميم مطابق للمرجع

تم بناء هذه النسخة اعتمادًا على الصورة المرجعية التي اختارها صاحب الموقع:
- شريط تنقل كحلي ثابت وروابط Home / Projects / Experience / Skills / Certifications / Contact.
- مقدمة بخلفية زرقاء فاتحة وعنوان ونبذة وأربعة مجالات تخصص.
- ثلاث بطاقات مشاريع مع الصور والأوصاف الحقيقية وروابط تعمل.
- أقسام للخبرات والمهارات والشهادات والتواصل.
- دعم العربية والإنجليزية، وشاشات الكمبيوتر والجوال.

## طريقة الاستخدام
1. افتح `index.html` في المتصفح لمعاينة الموقع.
2. ارفع الملفات والمجلد `assets/` إلى جذر مستودع GitHub العام.
3. من Settings > Pages اختر Deploy from a branch ثم main و / (root).
4. اختبر الأزرار والصور والتبديل بين اللغتين بعد نجاح النشر.

## محتوى المشاريع والخصوصية
- دليل موظفي الدراسات العليا مرتبط بموقع GitHub Pages المنشور.
- مشروعا Power BI وExcel يظهران عبر صفحات تفاصيل، وليس تنزيل ملفات الطلاب أو الدكاترة الأصلية.
- صور المشاريع مستندة إلى أعمال فعلية، وليست الأرقام التوضيحية الموجودة داخل الصورة المرجعية.
- صورة لوحة ساعات التدريس تعرض بيانات مجمعة بدون أسماء أو هويات.
- روابط الشهادات غير مضافة إلى أن تتوفر روابط تحقق أصلية.

**مهم:** الموقع لم يُرفع تلقائيًا إلى GitHub من هذه الحزمة. لا ترفع نسخة Excel الأصلية أو ملفات الطلاب إلى مستودع عام دون تصريح مناسب.
